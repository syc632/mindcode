# MindCode 软件功能介绍

## 1. 软件概述

MindCode 是一款面向程序员和技术学习者的桌面知识管理工具。它把编程概念、笔记内容和复习卡片组织到同一个知识图谱中，帮助用户从“记录知识”进一步走向“理解关系”和“持续复习”。

当前版本使用英文界面；本文以中文介绍功能。AI 提取的解释和卡片默认使用英文，引用证据保留原文语言。

软件的核心思路是：先把概念沉淀为节点，再用关系构成图谱，最后通过间隔重复机制推动长期记忆。用户既可以手动创建概念，也可以从本地文档或粘贴的笔记中生成知识图谱草稿。

## 2. 目标用户

MindCode 适合以下用户使用：

- 正在系统学习编程语言、框架、算法或工程实践的开发者。
- 需要把零散技术笔记整理成结构化知识图谱的学习者。
- 希望用复习卡片巩固概念、API、原理和代码模式的用户。
- 需要在本地保存学习资料，避免把个人笔记默认上传到云端的用户。

## 3. 核心功能

### 3.1 知识图谱

MindCode 提供可交互的知识图谱视图，用节点表示概念，用连线表示概念之间的关系。

主要能力包括：

- 以力导向图展示概念关系，帮助用户快速看到知识结构。
- 支持拖拽节点、平移画布和缩放视图。
- 支持展开或收起层级节点，便于在大型图谱中聚焦局部内容。
- 点击节点后查看概念说明、复习卡片、来源摘要和关联关系。
- 支持编辑或删除已有概念，持续维护知识图谱质量。

适用场景示例：

- 将 JavaScript 的 Promise、async/await、Event Loop、Microtask Queue 等知识点组织成运行时机制图谱。
- 把一个框架的核心模块、数据流和 API 依赖整理成可浏览的概念网络。

### 3.2 概念库

概念库用于集中浏览和管理所有知识节点。相比图谱视图，概念库更适合快速检索、清点和进入具体概念。

主要能力包括：

- 按更新时间和层级关系展示概念列表。
- 支持搜索概念名称、卡片内容和来源笔记。
- 显示概念分类、待复习数量和下次复习状态。
- 支持键盘上下选择和回车打开概念详情。
- 支持快速删除不再需要的概念。

适用场景示例：

- 查找某个技术概念是否已经整理过。
- 快速定位今天需要复习的知识点。
- 对导入或 AI 生成后的概念进行二次清理。

### 3.3 间隔重复复习

MindCode 内置基于 SM-2 思路的复习机制，为每个概念维护复习卡片和下次复习时间。

主要能力包括：

- 自动筛选当前到期的复习卡片。
- 以卡片形式展示问题，用户输入自己的答案后再查看标准答案。
- 根据回答是否匹配，更新卡片的复习间隔、复习次数和下次复习时间。当前采用忽略大小写、首尾空白和连续空白后的文本精确匹配，不是 AI 语义评分。
- 支持在答案区域展示代码示例，适合复习 API 用法、语法模式和工程实践。
- 复习结果会回写到概念数据中，形成持续学习记录。

适用场景示例：

- 复习“闭包是什么”“Promise 回调为什么进入微任务队列”等概念题。
- 复习某段代码背后的运行机制或最佳实践。
- 每天打开软件，只处理已经到期的卡片。

### 3.4 手动创建概念

用户可以在添加视图中快速创建单个概念，并为它生成第一张复习卡片。

主要能力包括：

- 输入概念名称、父级概念和解释说明。
- 可选填写复习问题、卡片答案和代码示例。
- 如果未单独填写答案，可复用概念解释作为卡片答案。
- 创建前提供卡片预览，便于确认问题和答案是否清晰。
- 新概念会立即进入图谱、概念库和复习队列。

适用场景示例：

- 学到一个新 API 后立即添加到图谱。
- 看文档时随手记录一个核心概念。
- 为已经理解但容易遗忘的知识点补充复习卡片。

### 3.5 AI 概念提取

MindCode 支持从笔记、代码片段或本地文档中生成知识图谱草稿。配置 DashScope API Key 后，软件可以调用 Qwen 模型提取概念、说明、卡片和关系。

主要能力包括：

- 从粘贴的笔记或代码片段中生成概念草稿。
- 从本地文档中读取内容并生成图谱草稿；调用云端 AI 时，待提取文本和已有概念名称会发送到 DashScope。
- 生成后先进入草稿预览，不会直接写入正式图谱。
- 用户可以逐个检查概念，修改名称、分类、父级、解释、问题和答案。
- 支持接受或跳过单个概念。
- 支持处理重复概念：跳过、追加卡片到已有概念，或重命名后创建新概念。
- 支持确认、编辑或取消生成的概念关系。

AI 能力的定位是“辅助整理”，最终写入前仍由用户确认，避免把低质量或不准确的内容直接污染知识库。

### 3.6 本地文档扫描

桌面端支持选择本地文件或文件夹进行扫描，并把文档内容送入概念提取流程。

当前支持的内容类型包括：

- Markdown：`.md`
- 文本：`.txt`
- 常见代码和前端文件：`.js`、`.jsx`、`.ts`、`.tsx`、`.py`、`.json`、`.css`、`.html`
- PDF：`.pdf`
- Word 文档：`.docx`

扫描过程中会跳过过大的文件，并对超长内容做截断处理，降低一次性导入过多内容导致的失败风险。基于本地文档扫描生成草稿时，需要配置 DashScope API Key。

### 3.7 多图谱文件管理

MindCode 支持维护多个独立图谱，适合把不同学习主题分开管理。

主要能力包括：

- 创建新的图谱。
- 在已有图谱之间切换。
- 删除不再需要的图谱。
- 打开、导入和导出 `.mindcode.md` 文件。
- 图谱文件以 Markdown 为载体，同时保留完整的 MindCode 数据块，兼顾可读性和可恢复性。

适用场景示例：

- 为 JavaScript、React、系统设计分别建立图谱。
- 把某个课程或项目的知识点导出为独立文件。
- 在不同设备或项目之间转移学习资料。

### 3.8 本地优先的数据保存

MindCode 是本地优先的桌面应用。默认数据保存在 Electron 的用户数据目录中，而不是项目仓库中。

主要数据包括：

- 主数据文件：`mindcode-data.json`
- 图谱文件目录：`maps/`
- 自动备份目录：`backups/`
- AI 配置文件：`ai-config.json`

软件会对数据进行规范化处理，确保节点、关系和卡片在写入前符合统一结构。API Key 保存在本机用户数据目录，不会写入代码仓库。浏览器模式下，软件会回退到 `localStorage` 保存数据。

## 4. 典型使用流程

### 4.1 从零开始整理一个主题

1. 新建一个图谱，例如“JavaScript 异步机制”。
2. 手动添加第一个核心概念，例如“Event Loop”。
3. 继续添加 Promise、Microtask Queue、async/await 等相关概念。
4. 在概念详情中补充关系和复习卡片。
5. 每天进入复习视图完成到期卡片。

### 4.2 从已有笔记生成图谱

1. 在添加视图中粘贴笔记，或选择本地文档。
2. 点击生成图谱草稿。
3. 逐个检查 AI 提取出的概念、解释和卡片。
4. 跳过不需要的概念，修正不准确的内容。
5. 确认关系后写入当前图谱。
6. 回到图谱视图查看整体结构。

### 4.3 持续复习和维护

1. 打开复习视图，查看今天到期的卡片。
2. 输入答案并提交。
3. 对照标准答案和概念说明。
4. 软件自动更新下次复习时间。
5. 在概念库中搜索和清理过期、重复或低质量内容。

## 5. 功能价值

MindCode 的价值不只是保存笔记，而是把学习过程拆成三个可持续的动作：

- 结构化：把零散笔记转换为概念、层级和关系。
- 可检索：通过概念库和图谱快速找回知识。
- 可复习：通过 SM-2 卡片把短期理解变成长期记忆。

对技术学习来说，这种方式比单纯写笔记更适合处理复杂知识网络，例如语言机制、框架架构、系统设计、算法专题和项目经验复盘。

## 6. 当前版本边界

当前版本主要面向本地桌面使用，重点覆盖知识图谱、概念整理、AI 辅助提取和间隔重复复习。它不是团队协作型知识库，也不是通用文档编辑器。对 AI 生成内容，用户仍需要人工审核后再写入图谱。

这一边界使 MindCode 更适合作为个人技术学习和复习工具：轻量、本地、可控，并围绕“概念理解”和“长期记忆”设计。
